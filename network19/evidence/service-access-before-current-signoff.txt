Grafana隧道可按需建立（若本任务现有13000已占用，直接访问即可）：

```bash
ssh -N -i ~/.ssh/yang_local_rsa \
  -o IdentitiesOnly=yes -o BatchMode=yes \
  -o StrictHostKeyChecking=yes \
  -o UserKnownHostsFile=/Users/yangzhaohui/work/www/harness/dell/private/known_hosts \
  -L 127.0.0.1:13000:10.63.30.40:3000 root@192.168.21.22
```

该隧道依赖终端/进程存活，不代表新公开监控域名。来宾管理用ub，严格host key和中转实现见`scripts/control.py`；不要复制客户端私钥或用关闭host key检查替代信任。

## 发布与回退

现行发布流程：[受限发布说明](infra/publisher/README.md)及[验收](infra/publisher/ACCEPTANCE.md)。只允许220的独立publisher向240使用固定协议暂存manifest/JAR/YAML、激活、回退和查询；它不提供root shell、SFTP、端口转发或任意脚本上传。只支持本期测试五服务，不扩到正式节点。

持久配置root:root0600，经systemd LoadCredential只读交给finger；应用日志与上传写在各自`/var/log/finger`、`/var/lib/finger`。回退仅应用制品和配置，不回退SQL、Nacos或新用户数据。旧dataId/release保留；禁止覆盖同ID或把数据库变化当JAR回退。

服务器实际固定部署代码以`infra/publisher/deployed/vm240`及`publisher-installed-code.json`为准。本地停止策略候选仍pending未部署；不得把候选30项测试和active27项混作一版，重新安装须重新核对。

## 备份与限制

当前初始副本：OS基线+CI侧文件、Nacos元库/Redis RDB/Rabbit definitions、Grafana SQLite/配置、Penpot官方应用包、Nexus hosted资产均有私有保留与相应恢复/导入证据。Mac是临时独立副本目的地，日常持续调度/容量/保留与长期恢复硬件仍需另行定案；不能宣称已达到候选RPO/RTO。

CF归档仅留PVE；发布私钥仅220。Rabbit definitions不含消息，当前Redis初始快照0keys，当前正式业务空，不等于真实业务恢复。NAS家庭媒体不作正式业务备份目标。不要直接打包整个private目录混入CF/无关源身份或越过私钥范围。

本期用户明确只启用**服务器内部Lark**；Mac外部探针因本地网络隐私阻拦已停用并移除实际登录任务，误告警已更正。T630整机故障会同时停止机内监控；不宣称独立全天候外部告警。Mac探针源码/诊断仅保留审计，本期不继续申请Python网络权限。

真实电视/PS4/PS5工具、4K/HDR/字幕音轨、GPU转码及生产并发SLO未验；当前验证覆盖SMB权限/合成文件完整性和合成影片DirectPlay协议，不承诺主机直接从NAS运行游戏。
